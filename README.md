## About the project
Inspired by Bristol.pub, a bath equivalent - tick off all your favourite pubs in Bath and try and sip a pint at them all!

Quite a few pubs missing, will add soon in one fell swoop.

## Getting started
Simply download and open the html file and tick pubs to your hearts content. Ticked pubs are saved.
